# Appliance_energy_forcasting
Forecasting household appliance energy use using UCI dataset. Compares 8 models — naïve benchmarks, SARIMAX with AIC grid search, XGBoost with engineered features, and Chronos foundation model. XGBoost achieves best performance (MASE=0.633). Full reproducible pipeline with stationarity tests, ACF/PACF, and evaluation metrics.
